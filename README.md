# Bot-with-AI

ENG:
This telegram bot was created in order to recognize which bird is depicted in the picture that the user will send. The program uses imageai to recognize the objects in the picture so that the program accurately understands that there is a bird in front of it. Keras, tensorflow, and numpy libraries are also used to classify birds.

The bot can recognize only 3 types of birds: pigeon, lark, tit.

To launch the bot, you need to download libraries such as:
telebot, pillow, numpy(version 1.26.4), tensorflow(version 2.12), keras(version 2.12), torch, torchvision, cv2, imageai

You also need to download the yolov3 model(https://github.com/OlafenwaMoses/ImageAI/releases/download/3.0.0-pretrained/yolov3.pt/) and move it to the models folder

RUS:
Этот телеграмм бот создан для того, чтобы распознавать какая птица изображена на картинке, которую отправит пользователь. Программа использует imageai для распознавания объеков на картинке, чтобы программа точно поняла, что перед ней птица. Так же используются библиотеки keras, tensorflow и numpy для классификации птиц.

Бот может распознать только 3 вида птиц: голубь, жаворонок, синица.

Чтобы запустить бота, вам надо скачать такие библиотеки, как:
telebot, pillow,numpy(версия 1.26.4), tensorflow(версия 2.12), keras(версия 2.12), torch, torchvision, cv2, imageai

Также надо скачать модель yolov3(https://github.com/OlafenwaMoses/ImageAI/releases/download/3.0.0-pretrained/yolov3.pt/) и перенести в папку models
